# Cisco Packet Tracer Labs

## Project Overview

This repository documents a series of simulated network projects built with Cisco Packet Tracer. The projects model connected environments ranging from small departmental LANs to larger institutional, hotel, and company networks.

Across the labs, the work focuses on planning network layouts, configuring routers and switches, organizing traffic with IP subnets and VLANs, enabling communication between network segments, and applying security and availability features where the project requires them. Each lab is a practical record of a network design: its Packet Tracer topology, implementation notes, and supporting configuration or verification evidence when available.

The goal is to make each design understandable and reproducible, not just to provide a `.pkt` file. Start with a lab guide to see that project's scope and materials.

## Getting Started

1. Install Cisco Packet Tracer.
2. Choose a project from the index and read its guide to understand the network and available files.
3. Open the `.pkt` file in that lab's folder with Cisco Packet Tracer.
4. Compare the simulated topology with the lab's addressing plan, configurations, and verification evidence where provided.

Packet Tracer `.pkt` files are editable simulation projects; they are not documents to read in a text editor.

## What Each Lab Contains

Lab folders are organized around their individual projects. Depending on the lab, supporting materials may include a README, addressing information, device configuration exports, screenshots, or verification notes. Refer to the lab guide for the exact contents; documentation depth varies across projects.

The `NOTEPAD/` folder contains additional networking command and configuration reference notes.

## Router Configurations

Use the [Router Configuration Library](ROUTER-CONFIGURATIONS.md) to find router configuration exports and lab-specific configuration guides.

## Topics Practiced

Topics represented across the projects include IPv4 addressing and subnetting, VLANs and trunking, inter-VLAN routing, static and dynamic routing, DHCP and network services, redundancy, secure device administration, and connectivity testing. Not every topic appears in every lab; each guide describes the scope of its project.
